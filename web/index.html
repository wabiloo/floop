About Floop


        
Floop is Boop on any device: a scratchpad for transforming text with small
          JavaScript scripts: format JSON, encode Base64, sort lines, hash, and much more. Type or paste text,
          pick a script, and it rewrites your selection (or everything).

        
It's a port of Boop,
          the macOS text tool by Ivan Mathy (MIT licence), and runs Boop's own scripts unchanged. Any script written for
          Boop works here too. Floop is not affiliated with the Boop project.

        
Source and scripts live in wabiloo/floop.
          Built with Claude Code. Icons by Font Awesome Free (CC BY 4.0) and, for scripts, Icons8 (as used by Boop); fuzzy search by Fuse.js.

Fetch URL

    

      
Tip: with a URL selected in the text (or the caret in it), the button fetches it straight away; Shift-click it to edit the headers first. Sends an HTTP GET and replaces the editor text with the response body. The server has to allow requests from other sites (CORS).

      
      
      
Kept on this device and sent with every fetch. Custom headers need the server's CORS settings to allow them.
